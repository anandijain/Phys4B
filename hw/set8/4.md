4. An otherwise infinitely straight line of current I has a circular
loop of radius R coiled in it such that the center of the loop is its
own radius above the wire and tangent to the straight length of
the wire. Find the magnetic field at the center of the loop. You
must include the field from the straight part of the wire as well
as the loop

# soln

B = Bloop + Bline (POS)

Bline:

use amperian loop and find 

cint B dot dl = mu0 I
cint B dl cos 0 = mu0 I         | see that the angle is always zero because this dl traces clockwise when viewed from \otimes (-khat)
                            | and by 2 step rhr we see B is parallel to this everywhere 
cint B dl = mu0 I           | see that B's magnitude is constant for fixed distance from current
B cint dl = mu0 I
B L = mu I 
B = mu I / (2 pi r) khat    | khat is not everywhere but specifically at the test point 

Bloop:
this one requires biot savart 
B = int dB (pos) = int mu/4pi * Idl cross rvec / r3 

we could use the previous result for the magnetic field on the axis of a ring of current 

l(theta) = (R cos theta, R sin theta, 0)
dl/dtheta = (-R sin theta, R cos theta, 0)

we called the center of the circle the origin
rvec = 0vec - l(theta)
    = (-R cos theta, -R sin theta, 0)
    = -R (cos, sin)

r = R  (obvious)

Idl = I dtheta * dl 
    = I dtheta * (-R sin theta, R cos theta, 0)
    = I R dtheta * (-sin, cos, 0)


Idl x rvec 
det [
    i         j          k
    -sin      cos         0
    cos      sin          0
]

khat * (I R dtheta) * (-R) (-sin2 - cos2)
khat * (I R dtheta) * (-R) * -1 (sin2 + cos2)
Idl x rvec = khat I R2 dtheta

dB = mu / 4pi * khat I R2 dtheta / R3 
B = int mu / 4pi * khat I R2 dtheta / R3 
    = khat mu I / (4 pi R) int (0, 2pi) dtheta      | int -> 2pi 
    = khat mu I / (2 R) 

B = Bloop + B line
    = khat mu I / (2 R) + mu I / (2 pi R) khat
    = khat mu I / (2 R) (1 + 1/pi)
