3. Find the magnetic field along the axis of a single loop of
current, I, of radius, a

# soln

we have a ring on the yz plane with a current going through it

the direction of current I is such that the tangent dl is pointing into the board at the top of the ring and towards us at the bottom

there is a point P = [x, 0, 0] where we want to find the b field. 

the path traced by the ring is i think l(phi) = [0, a cos phi, a sin phi]
but then dl/dphi = [0, -a sin phi, a cos phi]

the current element at the top (0, a, 0) corresponds tho phi = 0 so we want dl to point toward -khat there

if we plug in 0 into dl/dphi we get [0, 0, 1] which is +khat. so the path l(phi) must be [0, a cos phi, -a sin phi]
which would give dl/dphi = [0, -a sin phi, -a cos phi] which gives the appropriate sign

we need to use biot savart

first see that if the current is going away from us then the B is pointing down and to the left 
let k = mu0/4pi
B = int dB  (POS )
    = int dBx + int dB_perp     | perp zero by symmetry
    = int dBx 
    = int dB cos theta * -ihat      | theta is the angle made (origin, current element, P)
    = -ihat int k Idl cross rvec cos theta / r3         | eval cross with polar:  ||Idl|| ||rvec|| sin alpha. ||Idl|| = I a dtheta. ||rvec|| = r = sqrt(x2 + a2)
    = -ihat int k I a dtheta r sin alpha cos theta / r3     | sin alpha -> 1 since alpha alwayts 90. cos theta = a / r 
    = -ihat int k I a dtheta r a /r  / r3     |
    = -ihat k I a2 int dtheta  / r3     |
    = -ihat mu0 / 4pi I a2 2pi / r3     |
    = -ihat mu0 I a2 / (2r3)     |
