first we start with a simpler problem and work up

imagine a circular disk with radius R and total charge Q is on the xz axis and spins counter clockwise with angular velocity omega 

there is a B field Bvec = B ihat so 

we want to find the torque on the disk



soln 

the idea is that we basically have a bunch of loops which have torques dTau = dmu cross B 

we need to find the magnetic moment mu

mu = int dmu 

mu = I A (A for area)
so dmu = A dI nhat | normal is also jhat 

dI = dq/T where T is a period so omega * T = 2pi so T = 2 pi / omega

dq / dA = sigma = Q / (pi R2)
so dq = sigma dA | dA is a small area strip which is the area of the loop so 2 pi r dr

dq = sigma 2 pi r dr 

dmu = A dI jhat
    = A dq / T jhat
    = A sigma 2 pi r dr omega / 2pi

mu = A sigma omega int r dr 
    = sigma omega pi int (0, R) r3 dr 
    = sigma omega pi R4 / 4
    = Q omega pi R4 / (4 pi R2)
    = Q omega R2 / 4 jhat

so Tau = mu cross B
