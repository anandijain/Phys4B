6. A conducting bar of mass m is placed along a conducting inclined
plane of angle θ such that the bar completes a circuit with the edges of
the plane and then there is a current through the bar I. There is gravity in
this problem. Say that there is a uniform magnetic field that is vertically
up. Find the value of the current I such that the bar has zero acceleration.
Also, find the normal force of the plane on the bar.


# soln

F = m a     | a = 0 by problem
Fn + Fg + Fb = 0

Fg = -m g jhat 

Bvec = B jhat 

rod = current I mass m going back -khat 

F_B = IL cross B = I L B ihat 

so now 

I L B ihat - m g jhat + Fn = 0 

Now let N be the magnitude of the Fn and imagine what direction it is pointed in

by definintion it must be 90 degrees from theta 
so if theta vector is [cos, sin] then nhat = [-sin, cos]

then we can write Fn = [-N sin theta, N cos theta, 0]

this gives system of equations:
ILB = N sin theta
mg = N cos theta

simplify I 
I = mg tan theta / (L B)
