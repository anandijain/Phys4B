first you need to remember that if two capacitors are in series

C = Q / V 

C1 = Q1 / V1 
C2 = Q2 / V2

because the middle (connected node) has zero net charge then the charge on the bottom of C1 and top of C2 must be equal 

thus Q1 = Q2 

so C1 = Q / V1 
Q = C1 V1 
    = C2 V2 
C2 = Q / V2 

so we can solve for one capacitors voltage in terms of the other

since the middle is grounded and we want to find the potential at the top of C1 

we will need to see that the series caps are in parallel with r2 so if we find the drop across r2 
we can relate that to the drop across the caps. 

we use voltage divider 

vr2 = V R2 / (R1 + R2)

since we know this drop, we can make a kirchoff loop made of R2 C1 and C2 

this allows us to solve for the voltage across c1 (or c2 )
