given two circuits here is the common parts. the first circuit is only the following without rL
the supply voltage of v1 is unknown/ not provided (call it x)

V1(c, a) = x
r1(a, b)
r2(b, c)
gnd(c)

in circuit two there is an additional resistor
rL(b, c)

the drop across rL given as Vl. 

problem: find the Voltage at b in circuit 1 (without the load resistor) in terms of r1 r2 rl Vl only

# solution

first see that we can find the equivalent parallel resistor rp for the r2 and rl 

rp = r2 rl / (r2 + rl)

then we can find the original supply voltage 

quickly derive the formula for a voltage divider (not shown)

x rp / (r1 + rp) = vl   | the drop vl is given. use it to solve for supply voltage x

x = vl (r1 + rp) / rp

now that x is given we can apply the voltage divider equation again to the original circuit

x r2 / (r1 + r2) = V(B)

= vl (r1 + rp) / rp * r2 / (r1 + r2)
    = vl (r1 + (r2 rl / (r2 + rl))) / (r2 rl / (r2 + rl)) * r2 / (r1 + r2)
