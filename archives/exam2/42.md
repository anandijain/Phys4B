first find the force due to the magnetic field, then solve for the radius of the helix
use that to derive the equation for the period of the helix

then because the acceleration is not 0 we
then use kinematics x(t) = x0 + vx * t + 1/2 a t2 to find the x displacement after one period

the force of the uniform magnetic field B on q, F(B->q) = q (v cross B)
F_Bvec = q * det [
    i          j           k
    vx          vy          vz
    B           0           0
]
= ihat * 0 -jhat * - B Vz + khat * - B Vy
    = q B [0, Vz, -Vy]

It actually doesnt really matter we just need the norm 
call V_perp = sqrt(Vy2 + Vz2)
so F_B = q B V_perp
then since it is directed inward the radial force
F_B = m a
q B V_perp = m V_perp2 / r
...
r = m V_perp / (q B)

then V_perp * T = 2 pi r so V_perp = 2 pi r / T 
...
T = 2 pi m / (q B)

now that we have the period we just need the acceleration due to the electric field
F_E = q Evec = m a
=> a = q E / m 

x(T) = x0 + vx * T + 1/2 a T2
    = vx * (2 pi m / (q B)) + 1/2 q E / m (2 pi m / (q B))^2
...
    = 2 pi m Vix / (q B) + 2 pi2 m E / (q B2)
