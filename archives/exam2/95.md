# solution

because we are changing a current, we should immediately think faradays 

cint E dot dl = -d(Flux_B)/dt   | we apply a finite diff delta
cint E dot dl = -delta(Flux_B)/delta t
    = -(Flux_f - Flux_i)/ delta t
we are able to find the initial flux, and the final is zero as there is no current. you can easily show this with a quick application of amperes law by doing the rectangular closed line integral 

cint B dot dl = Ienc * mu0 | but Ienc = 0
B * L = 0       | but L nonzero => B = 0 => Flux_B = 0

cint E dot dl = Flux_i / delta t        | the best way to handle this is to prese

we use the solenoid approximation to see that magnetic field B is uniform inside = mu0 n I -khat and zero outside. the flux integral quickly evaluates to B * A = B * pi R2
Flux_i = mu0 I n pi R2

by the symetry of the cyl E has constant magnitude at a fixed r and is parallel to dl everywhere (or antiparallel?)

E * 2 pi r = Flux i / delta t
E = mu0 I n R2 / (delta t 2 r)

but what is E? 

Tau = Irot alpha   | how to remember to do this? remember the problem is related to a change in angular velocity
Tau = Irot (omega_f - omega_i) / delta t    | omega_i = 0, what is the torque? is angular velocity a vector, 

dTau = rvec cross dF
    = rvec cross Evec dq
Tau = int rvec cross Evec dq   | what is rvec and Evec

rvec = [r cos theta, r sin theta, 0]

Ehat can be determined by reasoning about "what counteracts the change in magnetic flux?" 

If we cut off the curent the direction of the change in flux will point positive +khat (out of page). 

Imagine though that we started spinning the ring of charge q counter clockwise, this creates a current that makes a magnetic field pointing also out of the page, 

but we want to oppose the change, therefore the E field must be directed azimuthally clockwise 

to derive the clockwise azimuthal vector, take -drvec/dtheat

Ehat = [sin theta, -cos theta, 0]
