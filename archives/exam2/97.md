bar: length=L at x=0 (vertical), mass=m, vi=0, on a circuit (left side) with width distance D and resistance R 

bar given acceleration = a ihat (to the right). 

Bvec = -khat B (into page)

what is the total amount of charge that passes through the resistor after the bar travels distance D 

# soln 

what is v(t)

v(t) = vi + a t = a t
x(t) = x0 + vi t + 1/2 a t2 
    = 1/2 a t2

what is the Emf(t)?

Emf = - d(Flux_B(t))/dt    | what is Flux_B

Flux(0) = int Bvec dot dA nhat  | lets choose the normal to be -khat, parallel with Bvec
    = B A  = B L D 

but how is the flux changing wrt t? 

B and L constant but D isnt

D - x(t) = width 
= D - 1/2 a t2 

d(Flux)/dt = d/dt (B L (D - 1/2 a t2))
    = -B L a t      | see that the flux is decreasing! good 
    = - B L v       | see the standard equation 

-d(Flux)/dt = B L a t = B L v 
Emf(t) = B L a t
now that we have the Emf(t), we can apply Ohm's law to find the current

Emf(t) = I(t) * R 
I(t) = B L a t / R
dq/dt = B L a t / R 
dq = B L a t / R dt 

int dq = int B L a t / R dt         | but what are the bounds? we need to make sure that the distance traveled is D
so we find when x(t) = D 
D - 1/2 a t2 = 0
t = sqrt(2 D / a)

int (0, Q) dq = int (0, sqrt(2 D / a)) B L a t / R dt        | for dq bounds could do (0, Q)

q =  B L D / R
