the key to finding magnetic moments is to remember that the task is to add up a bunch of small currents (which must be in the form of loops cuz thats what current is)


first quickly derive the surface charge density sig 

Q / A = sig 

A = pi(b2 - a2)
sig = Q / (pi(b2 - a2))

then write down 

mu = int dmu  
    = int A dI

but what IS dI. its a small current loop

imagine that we have a loop with thickness dr (so circum 2 pi r)
then the amount of charge on that loop will be sig * 2 pi r dr 

but we dont want the charge, we want the current

current is Q / Time. 

we know the ang velocity w 
so define T = period 

w * T = 2pi 
T = 2pi / w

Q / T = sig * 2 pi r dr  / 2 pi / w
    = sig w r dr 

that is the current dI 

the magnetic moment is the product of the area enclosed by the loop and the loop current
so A = pi r 2

mu = int (a, b) pi r2 sig w r dr 
    = pi sig w int (a, b) r3 dr 
    = pi sig w (b4 - a4)  /4 
    = pi q w (b2 - a2) (b2 + a2) / (pi (b2 - a2)) /4 
    = q w (b2 + a2)/ 4  khat 

the direction of the magnetic moment is the same as the direction of the angular velocity (i dont think this is always the case)

so the mu is khat and B is jhat 
so Tau (torque) is -ihat which i believe means at the first instant the spinning disk will turn to spin with its axis pointed toward -ihat
