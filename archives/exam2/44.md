find F_L (lorentz force) on a moving charge with two infinite lines of current and a uniform E field

uniform Evec = E khat everywhere
+q at (0, 0, d) with vvec = -vkhat
I1 traces (0, -y, 0)
I2 : (L, 0, z)

# solution 
F_L = F_E + F_B 

F_E = qEvec = q E khat

F_B = q(v cross B)  | hollup what is B 


B = B1 + B2 (POS)

first just do the thing and derive that amps law
and use two, 2-step rhrs to find the direction of the B1 and B2 
just dont forget that we are talking about two different currents I1 and I2 

B = mu I / (2 pi r)

so B1 is distance d from q 

B1 = mu I1 / (2 pi d)    | by 2step direction is -ihat
B1 = -ihat mu I1 / (2 pi d)    

same thing for B2 

B2 = -jhat mu I2 / (2 pi L) 

B = - mu / (2 pi) (ihat I1 / d + jhat I2 / L)

now we need to find F_B = q(v cross B)

v = -v khat
v cross B = 

det[
    i           j           k
    0           0           -v
    I1/d        I2/L        0
]
F_B = -q mu/2pi * (ihat * I2 v / L - jhat v I1 / d)


F_L = q E khat + -q mu/2pi * (ihat * I2 v / L - jhat v I1 / d)
