dc circuit problem 
nodes: A:E 
recall voltage sources are defined - => +

v1(A, D) = 20V
v2(E, C) = 12V 
v3(B, E) = 10V

r1(D, E) = 10 ohm
r2(B, C) = 10 ohm
r3(E, B) = 20 ohm

c1(A, C) fully charged

Gnd(C)

find the potential at node A and B: V(A) and V(B)

# solution 

since C is gnd (0V) then E is -12V by v2
then B is -22V by v3 

since the cap is full, then v1 is not delivering any current, meaning no charge can flow through r1 

if I_r1 = 0 then V_r1 = 0 by ohms law, thus 

V(D) = V(E) = -12V 

by KVL we make a kirchoff loop: 

20 + 12 - V_C = 0
V = 32V 
so V(A) = -32

could also just see that since V(D) = -12 and the supply difference of v1 must be 20 then A must be -12 - 20 = -32
