# problem 

yz ring (rad=a, charge = Qring)
x axis rod(len=L, leftpos=[2a,0,0], charge=Qrod)

find mag |F(ring->rod)| 

# soln
first we find the electric field at a point on the x axis:
P = [x, 0, 0]

r = sqrt(a2 + x2)
dq = lam a dtheta
    = Q / 2 pi dtheta 

E = int dE (POS)
    = int dEx + int dE_perpendicular     | second int = 0 by symm
    = int k dq / r2 cos alpha ihat      | we know that dEx will be dE cos alpha (where alpha is the angle made by x axis, point P, and the charge element dq). if you draw it cos alpha = x / r
    = ihat k Q x / (2 pi r3) int(0, 2pi) dtheta    | r is only dependent on x and a so we can take out of integral
    = ihat k Q x / r3

now that we know the E field at a point on the rod we can integrate the force elements 

in this part of the problem dq/ds = Qrod/L = lam_rod
dq = Qrod/L dx


F = int dF
    = int E dq 
    = int(2a, 2a + L) ihat k Q x / r3 * Qrod / L dx 
    = ihat k Qring Qrod / L int(2a, 2a + L) x / r3 dx 
    = ihat k Qring Qrod / L int(2a, 2a + L) x / (x2 + a2)^(3/2) dx 

it turns out you can u sub this thing with u = x2 + a2 
you get 

F(ring->rod) = k Qring Qrod / L * (1/ (a sqrt(5)) - 1 / sqrt((2a + L)2 + a2))
