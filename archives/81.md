Problem: 
Dialectric sphere of radius R and density rho, center origin.

We have a +q charge with mass m at R/2 initially at rest. 

We want to find the velocity of the charge when it is released and is at position R (the surface of the sphere)

# try 2
The general strategy is find the E field inside the sphere. 
Then do a line integral to compute Delta V. 
Using this we can determine the work done on the system (q). 

First use gauss law concentric sphere 

cint E dot dA = qenc/ eps 
E * 4 pi r2 = rho * 4/3 pi r3 / eps
E = rho r / (3 eps ) rhat   | the field increases with r and is not k q / r2 so we must line integral

W = Delta U (sys = q)

-q Delta V = Delta KE 
    = KEf - KEi     | but KEi = 0 since it started at rest
    = KEf

Delta V:
    = -int(R/2, R) E dot dl = 
    = -int(R/2, R) rho r / 3 eps rhat * dr rhat   | the vectors cancel (parallel)
    = -int(R/2, R) rho r / 3 eps dr cos 0 
    = -rho/3eps int(R/2, R) r dr
    = -rho/3eps [ r2/2 @ [R/2, R]]
    = -rho/3eps * 3/8 R2 
    = -rho R2 / (8 eps)

so W = q rho R2 / (8 eps) = KEf
