We have a dielectric sphere (totalcharge=Q, rad=R, dens=rho, center=origin) 

If V(inf) = 0, find V at center. 

# solution

need to break down into 2 pieces since the E field is different inside and out

for outside the field will look like a point charge and we can find that V(surface) = k q / r = k Q / R 

now we need to use gauss law to find the field inside, let rad of concentric gauss sphere = r 

let rho = Q / vol 
    = Q / (4/3 pi r3)
    = 3Q / (4 pi r3)

so then qenc = rho * vol 
    = rho * 4/3 pi r3
    = Q a3 / (R3 eps)
flux: cint E dot dA = qenc / eps. qenc 
    E * 4 pi r2 = Q r3 / (R3 eps)

E = Q r / (4 pi R3 eps) rhat

now that we know the electric field we can integrate 

Delta V(surface->center) = 
    = -int(R, 0) E dot dl
    = -int(R, 0) Q r / (4 pi R3 eps) rhat dot dr rhat   | rhats parallel
    = -Q/((4 pi R3 eps)) int(R, 0) r dr  
    = -Q/((4 pi R3 eps)) [r2/2 @ (R, 0)] = [0 - R2/2]
    = Q R2 / (8 pi R3 eps)

now we add the two potential changes together to get teh potential at the center 

Delta V = DV1 + DV2 
    = k Q / R + Q R2 / (8 pi R3 eps)    | convert to using k
    = k Q / R + k Q / (2 R)
    = 3 k Q / (2 R)
