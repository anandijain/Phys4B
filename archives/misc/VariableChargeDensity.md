# Rod length L with charge density 

lam(x) = (p/L)(x-L/2)

find Q on rod

let left end be origin and on x axis

Q = int(0, L) lam(x) dx 
    = int(0, L) (p/L)(x-L/2) dx 
    = (p/L)(int(0, L) xdx - int(0, L) L/2 dx)
    = (p/L)(x2/2 @ (0,L) - Lx/2 @ (0,L))
    = (p/L)(L2/2 - L2/2)
    = 0
