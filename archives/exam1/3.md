# problem

2 infinite plates 
plate 1 @ x = 0 with density 2sig. call this plate V = 0
plate 2 @ x = -d with dens sig

P = [-2d, 0,0 ]

Find V(P)

# solution
E = E1 + E2 
use quick gauss law to find that 
E1 = sig/eps sign(x) ihat   | negative for negative x
E2 = sig/(2 eps) sign(x+d) ihat     | if x > -d then E points right

in between plates 
E = -sig/2eps ihat
to left:
E = -3sig/2eps ihat

Now to find the potential we take two line integrals
Delta V1 = -int(0, -d) E dot dl     | note that the antiparallel direction of the two vectors was already in the sign of -sig/2eps
    = -int(0, -d) -sig/(2eps) dx 
    = sig/2eps [x @ (0, -d)]
    = -sig d / (2 eps)

Delta V2 = -int(-d, -2d) E dot dl
    = = -int(-d, -2d) -3sig/(2eps) dx 
    = -3sig/2eps (x @ (-d, -2d))
    = -3 sig d / 2 eps 

Delta V1 + Delta V2 = 
    = -4 sig d / (2 eps)
    = -2 sig d / eps
