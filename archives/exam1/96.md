Infinite line of charge, dens=lam

Circle with center -3R and rad=R, mass=m

Find the charge required for equillibrium (static)

# soln 

F = m a is given away by "zero acceleration part"
F = m a (sys = ring)
Fe + Fg = 0 
Fe + -mg (jhat) = 0
Fe = mg jhat 

We can use gauss law on the wire

cint E dot dA = qenc/eps
E * 2 pi r L = lam L / eps
E(r) = - jhat lam / (2 pi r eps)
    based on the problem it is clear that the radial direction is in the -jhat direction

a small charge element dq can be made wrt dtheta (position around ring)

if we made the ring center the origin then the path traced is 

point(theta) = [R cos theta, R sin theta]

at theta = 0 distance to wire (r) is 3R. 

so r(theta) = 3R - R cos theta 
     = R(3-cos theta)

dq / ds = Q / (2 pi R)

ds / dtheta = R 
dq / dtheta = Q / (2 pi)
dq = Q / (2 pi ) dtheta


to find the F(rod->ring) = int dF
    = int E dq      | because the E is simple and found already we just need to add up all the small forces due to charge elements, not add up all the field elements
    = int(0, 2pi) - jhat lam / (2 pi r eps) Q / (2 pi ) dtheta
    = -jhat lam Q / (4 pi2 eps) int(0, 2pi) dtheta/r 
    = -jhat lam Q / (4 R pi2 eps) int(0, 2pi) dtheta/(3-cos theta)
    = 
so force balance 
-jhat lam Q / (4 R pi2 eps) int(0, 2pi) dtheta/(3-cos theta) = mg jhat
Q = -m g 4 pi2 R eps / (lam int(0, 2pi) dtheta/(3-cos theta))
