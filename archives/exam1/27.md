# problem

find the position of another Q = point(charge=Q, pos=?) such that

# soln

Find E(origin) with integral dE (POS)

P = [0,0]
dq @ [a cos theta, a sin theta]
if you take the norm of P-dq you get a

dq/ds = lam = Q / (pi a)
ds / dtheta = a 
dq = lam a dtheta

E = int dE (pos)
    = int dEx + int dEy     | right integral 0 by sym
    = int k dq / a2 * cos theta     | define theta between dq, origin and x axis
    = k lam / a int(pi/2, 3pi/2) cos theta dtheta 
    = k / a * Q / (pi a) * [sin theta @ (pi/2, 3pi/2)]
    = k Q / (pi a2) * -2    | how do you know what order to do the bounds? it seems like it shouldnt matter 

E = -2 k Q / (pi a2) = k Q / r2     | now solve for r 

r = a sqrt(-pi/2)
