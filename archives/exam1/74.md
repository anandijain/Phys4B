# problem:

Ring(charge=Q, radius=a) on yz plane. 
bead = charge(-q, m, vi=0, pos=(3a,0,0))

In the stated problem above prof gives a convoluted path that the charge must take, this is just a big tell to use the potential change, since that is independent of path and we can simply do a straight line integral

bead is released and we want to find the final velocity when the bead is at the origin. 

# solution

1) E(x) = integral dE (POS). can use symmetry pretty nicely 

It turns out actually I wasted a lot of time deriving dq but before you do this you should check that that is needed. 

E = int k dq / r2 * cos alpha
    = int k x dq / r3 
    = int k x dq / (x2 + a2)^(3/2)
    = k x / (x2 + a2)^(3/2) int dq    | how do we know we can pull x and a out of integral? neither x nor a are changing 
    = k Q x / r3 ihat

E(x) = x Q k ihat / (a2 + x2)^(3/2)

2) apply work energy theorem 

W = Delta U (sys = bead)
-(bead) * Delta V = Delta KE = KEf - KEi = KEf
-(-q2) * -int(3a, 0) E dot dl = 1/2 m vf2

the integral is moderately nasty and probably could be left unevaluated but can be done with u substitution

the integral becomes 
Delta V = 
    - Q k (1/(a sqrt(10)) - 1/a)

W = - q Q k (1/(a sqrt(10)) - 1/a) = 1/2 m vf2 
    vf = sqrt(-2 Q q k / (m a) * (1/sqrt(10) - 1))
