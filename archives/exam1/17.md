thick sphere shell CONDUCTOR w Ri = inner and Ro = outer. total charge 4q

in center there is q charge. 

find the inner and outer surface charge density. 

# soln

if we put a gaussian surface sphere w radii anywhere in (Ri, Ro) then the E is zero by property of conductors 

But if E is zero then the flux is zero  this implies that the enclosed charge is zero 

Gauss law: 

closed int E dot dA = q_net / eps

if lhs 0 then so is qnet 

for r < Ri qnet = q but that means that we must have -q of charge on the inner sphere shell

so we can now compute sig1 = -q / (4 pi Ri^2)

but we have charge conservation: that means that we still only specified that there is 4q total of charge on the hollowed sphere conductor so then a gsphere around the outer sphere must still enclose 5Q of charge

so the surface must have 5q on it if the total net charge on the sphere is 4q

thus sig2 = 5q/(4 pi Ro^2)
