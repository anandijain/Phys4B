infinite wire, uniform lam on x=0 z=0 (y axis)

q = charge(q, m; vi=0, pos=[d,0])

find vf when q at pos=[10d,0]. cannot use d in final answer 

# solution 
W = Delta U (sys = q)
-q Delta V = Delta KE = KEf - KEi   | KEi = 0 given

Find Delta V 
    = - int(d, 10d) E dot dl 

Find E with gauss law

E * 2 pi R L = lam L / eps
E = lam / (2 pi R eps) rhat

back to Delta V 
    = - int(d, 10d) lam / (2 pi R eps) rhat dot dr rhat     | rhat rhat, so vecs parallel
    = - lam / (2 pi eps)  int(d, 10d) dr / r 
    = - lam / (2 pi eps)[ ln(10d) - ln(d)]
    = - lam / (2 pi eps)[ ln(10d/d)]
    = - lam ln(10) / (2 pi eps)

so W = q lam ln(10) / (2 pi eps)    | sign checks out, we did positive work on q
    = 1/2 m vf2 
    sqrt(q lam ln(10) / (m pi eps)) = vf
