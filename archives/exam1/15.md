# problem: 

dialectric sphere (rad=R (not given)) with charge density 
rho(r) = p C r 

find the E field inside the sphere. 

# soln

by the symmetry of the sphere we know that 

Evec(theta, phi, r) = E(r) rhat (so it is radial and then for a fixed radius r' |E| is constant )

we then make a concentric gauss sphere with rad r < R 

we now know that by the 3 step checklist 1) E perpendicular nowhere on the sphere to dA 2) there is not equal flux in and out opposite sides 3) thus E_out = 0

cint E dot dA = qenc / eps 
E * 4 pi r2 = qenc/ eps
    = 1/eps int(0,r) rho(r) * dVol 
    = p C / eps int(0, r) r * r2 dr int(0, 2pi) dphi int(0, pi) sin theta dtheta     | note that the phi and theta integrals evaluate 
    = 4 pi p C / eps int(0, r) r3 dr 
    = 4 pi p C / eps [ r4/4 @ (0, r)]
    = r4 pi p C / eps 

E * 4 pi r2 = r4 pi p C / eps 

E(r) = r2 p C rhat / (4 eps)
