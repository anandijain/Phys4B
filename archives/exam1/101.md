# soln:

Tau = I alpha (sys = dipole)

We want to find the net torque on the system, then we can search for a term linear in a displacement (for rotation this will be theta). This is analogous to hooks law where F = k delta x (where k is the spring constant needed to find the period T)

Tau = Tau1 + Tau2 
    = (r1 cross F1) + (r2 cross F2)

r1 = [d/2 cos theta, d/2 sin theta, 0]
F1 = qE = q E ihat

Tau1 = det [
    i           j           k
    d/2 cos     d/2 sin     0
    q E 
]
    = -khat d q E sin theta / 2

by symmetry we can see that the net torque T_net = 2 * Tau1
    = -khat d q E sin theta 

now we can make a small angle approximation that sinx = x

    = -khat d q E theta         | but wait... now we have Tau linear in theta

spring constant k = d q E !!!

so period T = 2 pi sqrt(m / (d q E ))      ... right... ??????

no because mass is the property of a body that describes its resistance to non angular acceleration (linear)

what is mass analog for rotational motion... its rotational inertia     (I)

for one charge I = m r2 = m * (d/2)^2
but we have two charges = 2 * m d2 / 4 = m d2 / 2

so T = 2 pi sqrt((m d2 / 2) / d q E)
    = 2 pi sqrt(m d / (2 q E))
