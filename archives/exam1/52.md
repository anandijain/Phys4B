# problem 

there is a charge +q at origin

then there is a rod(charge=Q, len=L, mass=m, pos=[d,0] to [d, L])

no gravity in this problem

Given: a uniform mass rod has angular acceleration m L2 / 2

find the angular acceleration of the rod.

# solution 

The plan is to integrate dtau across the length of the rod, which will give us the total torque on the rod.

once the torque is found we can then solve for alpha = tau / I 
    = tau / (m L2 / (2)) 
    = 2 tau / (m L2)

now find torque: 
tau = I alpha   sys = rod. 
tau = r_tau cross F

but we have to add up a bunch of "small" forces 
r_tau in this part means the displacement from the rod pivot to the dF spot 

tau = r_tau cross dF
    = r_tau cross E dq  

but what is E?

use standard coulomb
E = k q / r2 rhat (this points away from the point charge at the origin) but the only force that exerts a torque will be the component of F that is perpendicular to the displacement vector from the pivot 

what is r? (magnitude of displacement from origin +q to the dF )
    = sqrt(d2 + y2)     | y is going to be the integration variable

now we can start to evaluate the cross product 

r_tau will be [0, y] (pretty obvious)
but we need to remove the non ihat part from dF
dFx = dF cos theta      | where theta is the angle made (x axis, origin, dF spot)
but we know cos theta = d / r

so what is dF now:
    = k q / r2 * d / r ihat
    = k q d / r3 ihat

so [0, y, 0] cross [k q d / r3 , 0, 0] (since dF must point ihat (perp) to have any torque contribution)

what is dq?

dq/dy = lam = Q / L so dq = lam dy 

i like to take the determinant to eval `cross`
det [
    i       j       k
    0       y       0
k q d / r3     0       0
]
dTau = -khat y k q d / r3 dq 

Tau = int dTau
    <!-- = int(0,L) y E dq  -->
    = int y k q d / r3 dq
    = -khat int(0,L) y k q d / r3 lam dy      | only add the limits when we have converted dq to real geometry 
    = -khat k q d lam int(0,L) y / (d2 + y2)^(3/2) dy 

it turns out this can be integrated easily with usub. the integral part becomes 
(1/d - 1/sqrt(d2 + L2))

tau = -khat k q d lam (1/d - 1/sqrt(d2 + L2))

we now have the torque and we just plug into 2 tau / (m L2)
alpha = 
    = 2 tau / (m L2)
    = 2 -khat k q d lam (1/d - 1/sqrt(d2 + L2)) / (m L2)
