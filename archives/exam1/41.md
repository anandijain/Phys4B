There is a dielectric sphere (centered at origin) radius R w uniform charge density rho. 

We cut a hollow out of it centered at [R/2, 0] with radius R/2. 

Find E(P) for P = [R/4, R/4].

# solution

my first attempt i thought i needed to first do principle of superposition and then do gauss law on each. but because the components of the E are spheres we can just treat them as point charges and use E(r) = kq/r2 rhat

In order to create the hollowed charge distribution we treat it as though it is a solid sphere without the hollow then add a second sphere centered at hollow with the opposite charge distribution (-rho)

E = E+ + E- (POS)
    = kQ+/(r+2)(r+hat) + kQ-/r-2 (r-hat)
First we find the displacement vectors from the center 

rvec+ = P - origin = P = [R/4,R/4]
r+ = sqrt((R/4)2 + (R/4)2)
    = R/sqrt(8)
    = R/(2 sqrt(2))

rhat+ = rvec+ / r+
    = 2 sqrt(2)/R * R/4 * [1,1]
    sqrt(2)/2 * [1,1]

basically the same math provides

rvec- = [-R/4, R/4]
r- = R/(2 sqrt(2))
rhat- = sqrt(2)/2 * [-1,1]

now we must find Q+ and Q-
theres a trick here to leave the radius in Q unevaluated (ie dont replace r with R/(2 sqrt(2))) because it will cancel nicely in the coulomb E 
Q+  = rho * Vol
    = rho * 4/3 pi r3 (for arbitrary r )

Q- = -rho * 4/3 pi r3 (notice that above we showed r- = r+)

E+ = k rho * 4/3 pi r3 / r2 * rhat+ 
    = 4 k rho pi r / 3 * sqrt(2)/2 * [1,1]
    = 4 k rho pi R / (3 * 2 sqrt(2)) * sqrt(2)/2 * [1,1]
    = k rho pi R / 3 [1, 1]

The same math gives 
E- = - k rho pi R / 3 [-1, 1]

E = E+ + E-
    = k rho pi R / 3([1, 1] - [-1, 1])
    = 2 k rho pi R / 3 [1, 0]
    = 2 k rho pi R / 3 ihat
