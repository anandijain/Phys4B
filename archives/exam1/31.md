# solution

this is an E = integral dE (POS) problem 

The curve is rvec = [R cos theta, R sin theta]

So the displacement from charge element dq to P
    = [x - R cos theta, - R sin theta]

r = sqrt((x - R cos theta)2 + (- R sin theta)2)

we can see that dE = k dq / r2 

circumference of circle rad R = 2 pi R, so the circum of half circle is just pi R

the charge distribution is uniform dq/ds = Q/(R*pi)

Here is where I get a little confused, the length on the arc for a dtheta will be R dtheta (by arclength formula)
then if lam is the linear charge density = Q / (R pi) 

so then shouldnt R dtheta * Q / (R pi) = dq 
    = Q dtheta / pi = dq 
dq = Q/pi dtheta 

so E = int(pi/2, 3pi/2) k dq / r2 rhat 

E = int(pi/2, 3pi/2) k lam R / r3 rvec dtheta 
    = k lam R int(pi/2, 3pi/2) dtheta / r3 * [x - R cos theta, R - R sin theta]
    = k Q / pi int(pi/2, 3pi/2) dtheta / r3 * [x - R cos theta, R - R sin theta]
