# Problem
Vertical rod with top end at origin of length L total charge Q (uniform).

Rod(Q, L, ([0, 0], [0, -L]))

Charge(q, m, [0, D]; vel_i = vi downward )

find the position where charge q has vf = 0.

# solution 
W = Delta U (sys = charged mass)

-q Delta V = Delta KE   | since just one particle there is only KE 
    = KEf - KEi     | only KEi since we want to find where vf = 0
    = - 1 / 2 m vi^2 

Now we find V(H)
dq = lam dy 

dq @ [0, y]
P = [0, H]
so r = [0, H-y] displacement vec from charge element to the point P
V = int(-L, 0) dV
    = int(-L, 0) k dq / r 
    = k lam int(-L, 0) dy / (H-y)

u sub u = H-y 
du = -dy
-int 1/u du = -ln(u)
    = -k lam ln(H) - ln(H+L)
    = -k lam ln(h/h+l)
    = k lam ln((h+l)/h)

now we find delta V (the change in potential from the )

    = Vf - Vi
    = k lam (ln((h+l)/h) - ln((d+l)/d)) 

so back to finding h 

-q Delta V = - 1/2 m v2
(ln((h+l)/h) - ln((d+l)/d))  = 1/(2 q k lam) m v2
ln((h+l)/h) = 1/(2 q k lam) m v2 + ln((d+l)/d)
let T = 1/(2 q k lam) m v2 + ln((d+l)/d)
(h+l)/h = exp(T)
1 + l/h = exp(T)
l/h = exp(T)-1
h = l/(exp(T)-1)
