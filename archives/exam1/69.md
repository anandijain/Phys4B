# problem:

infinite dielectric cylinder rad=R, dens=rho

Q = point(charge=Q, mass=m, pos=cylinder axis, vi=0)

Q is released from rest, what is the velocity when it reaches the cylinder surface

# soln

first gauss law on interior concentric cylinder 

you find 
E(r) = rho r rhat / 2 eps

Now we can do a line integral to determine the work done

W = Delta U (sys = Q)
     = Delta KE (no potential for a single charge)
     = KEf - KEi | from rest so KEi =0
     = KEf
= -Q Delta V 

Delta V = - int(0, R) E dot dl 
    = - int(0,R) rho r rhat / 2 eps dot dr rhat | rhats parallel
    = -rho / (2 eps) int(0, R) r dr => (r2/2 @(0, R) = R2/2 - 0 = R2/2)
    = - rho R2 / 4 eps 

W = Q rho R2 / (4 eps)  | good work is positive makes sense
    = 1/2 m vf2

vf = sqrt(Q rho R2 / (2 m eps))
    = R sqrt(Q rho / (2 m eps))
