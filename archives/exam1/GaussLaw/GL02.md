Problem:

Infinite dielectric cylinder with radius R and uniform charge density rho
The axis of the cylinder is khat
The cylinder has an infinite cylindrical hollow with its axis at z=R/2 and the radius is R/2. 

Find E at z=3/4 R 

# solution

The key here is thinking in principle of superposition (POS).

We can model this charge distribution as an infinite solid cylinder of dnesity rho and a second offset cylinder with -rho density

We can then apply gauss's law to each separately to find E at a given point 

E = E_+ + E_-

E_+ : 

qenc for r = 3/4R  and length l
l * pi r2 = 
rho *l * pi * (3/4R)2 = 
qenc = 9 rho l pi R2 / 16 

flux = cint E dot dA =  9 rho l pi R2 / (16 eps)
we can break up the flux into 

int cap1 + int cap2 + int side = ...    | the caps are zero because by symmetry the Evec = E(r) rhat (radial). also this means that for the side theta = 0 and caps theta = 90 (so cos 90 = 0)
int side E dA cos 0  = 9 rho l pi R2 / (16 eps)
E int dA = 9 rho l pi R2 / (16 eps)     | int dA will be the area of the side
E * 2 pi (3R/4) l = 9 rho l pi R2 / (16 eps)
E+ = 3 rho R / (8 eps)

we can do the same exact thing now for E- but using -rho density and radius = R/4

E- = -rho R / (8 eps)

so E = -rho R / (4 eps) jhat    | jhat given in problem diagram
